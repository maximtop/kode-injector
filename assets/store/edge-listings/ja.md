# Microsoft Edge Add-ons 掲載情報 — 日本語

- Locale: `ja`
- Product name: `Kode Injector`

## 詳細な説明

Kode Injector は、必要なウェブサイトにローカルの JavaScript ファイルや CSS ファイルを関連付けます。ホスト名のルールを作成し、JS ファイル、CSS ファイル、またはその両方を選択すると、一致するページを開くたびに拡張機能がコードを自動的に適用します。

修正のテスト、反復チェックの自動化、公開中サイトのレイアウト調整、ローカルビルドとステージング環境や本番環境との比較を行うウェブ開発者、QA エンジニア、デザイナー向けです。再読み込みのたびに同じスニペットを DevTools に貼り付ける必要はありません。

機能:

- 一致するウェブサイトでローカルの JavaScript と CSS を自動実行。
- わかりやすい設定ページでルールの作成、編集、複製、一時停止、削除が可能。
- 個別のファイル、1 つのウェブサイト、またはすべてのインジェクションをまとめて有効化または無効化。
- ツールバーのポップアップから一致するルールを確認し、現在のサイトの状態を変更。
- Microsoft Edge 標準のローカルファイルアクセスを使用。高度な代替手段として読み取り専用の Kode Injector Helper も選択可能。
- ライトテーマとダークテーマに対応した 30 言語のインターフェイス。

Kode Injector には、分析サービス、広告、開発者が運用するバックエンドはありません。ルールが一致すると、選択したコードは設定したウェブサイトのページに公開され、JavaScript ファイルの URL はそのページの診断コンソールログに記録されます。信頼できるコードとウェブサイトだけを設定してください。詳しくはプライバシーポリシーをご確認ください。

インストール後、Kode Injector の設定を開き、ファイルアクセスの案内に従ってください。ウェブサイトのルールを追加し、ローカルコードを選択してページを再読み込みします。
