## توضیحات کامل

Kode Injector فایل‌های JavaScript وCSS محلی را به وب‌سایت‌هایی که به آن‌ها نیاز دارید متصل می‌کند. برای یک نام میزبان قانون بسازید، یک فایل JS محلی، یک فایل CSS یا هر دو را انتخاب کنید؛ افزونه هر بار که صفحه‌ای مطابق باز می‌کنید، کد شما را به‌طور خودکار اعمال می‌کند.

این افزونه برای توسعه‌دهندگان وب، مهندسان تضمین کیفیت و طراحانی ساخته شده است که می‌خواهند یک اصلاح را آزمایش کنند، بررسی تکراری را خودکار کنند، چیدمان یک سایت فعال را تغییر دهند یا بدون جای‌گذاری دوباره همان قطعه‌کد در DevTools پس از هر بارگذاری، ساخت محلی را با محیط آزمایشی یا عملیاتی مقایسه کنند.

ویژگی‌ها:

- اجرای خودکار JavaScript وCSS محلی در وب‌سایت‌های مطابق.
- ساخت، ویرایش، تکثیر، توقف موقت و حذف قوانین از یک صفحه تنظیمات متمرکز.
- فعال یا غیرفعال کردن فایل‌های جداگانه، یک وب‌سایت یا همه تزریق‌ها به‌طور هم‌زمان.
- مشاهده قوانین مطابق و تغییر وضعیت سایت فعلی از پنجره بازشوی نوار ابزار.
- استفاده از دسترسی داخلی Microsoft Edge به فایل‌های محلی، یا انتخاب Kode Injector Helper فقط‌خواندنی به‌عنوان گزینه‌ای پیشرفته.
- استفاده از رابط کاربری به ۳۰ زبان با پوسته روشن و تیره.

Kode Injector هیچ سرویس تحلیل، تبلیغات یا سامانه پشتیبانیِ تحت مدیریت توسعه‌دهنده ندارد. وقتی قانونی مطابقت دارد، کد انتخاب‌شده در اختیار صفحه وب‌سایت پیکربندی‌شده قرار می‌گیرد و نشانی URL فایل JavaScript در گزارش تشخیصی کنسول همان صفحه درج می‌شود. فقط کد و وب‌سایت‌هایی را پیکربندی کنید که به آن‌ها اعتماد دارید. برای جزئیات، سیاست حفظ حریم خصوصی را بخوانید.

پس از نصب، تنظیمات Kode Injector را باز کنید و راهنمای دسترسی به فایل‌ها را دنبال کنید. قانونی برای یک وب‌سایت اضافه کنید، کد محلی خود را برگزینید و صفحه را دوباره بارگذاری کنید.
