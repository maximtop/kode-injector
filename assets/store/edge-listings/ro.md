# Listare Microsoft Edge Add-ons — română

- Locale: `ro`
- Product name: `Kode Injector`

## Descriere completă

Kode Injector conectează fișiere JavaScript și CSS locale la site-urile web pe
care aveți nevoie de ele. Creați o regulă pentru un nume de gazdă, alegeți un
fișier JS local, un fișier CSS sau ambele, iar extensia aplică automat codul de
fiecare dată când deschideți o pagină corespunzătoare.

Extensia este creată pentru dezvoltatori web, ingineri QA și designeri care
trebuie să testeze o remediere, să automatizeze o verificare repetitivă, să
ajusteze aspectul unui site publicat sau să compare o versiune locală cu un
mediu de preproducție ori de producție, fără să lipească același fragment în
DevTools după fiecare reîncărcare.

Funcții:

- Rulează automat JavaScript și CSS locale pe site-urile web corespunzătoare.
- Creează, editează, duplică, pune pe pauză și șterge reguli dintr-o pagină de
  opțiuni bine organizată.
- Activează sau dezactivează fișiere individuale, un site web sau toate
  injectările simultan.
- Afișează regulile corespunzătoare și schimbă starea site-ului curent din
  fereastra pop-up a barei de instrumente.
- Folosește accesul integrat al Microsoft Edge la fișiere locale sau, ca
  alternativă avansată, Kode Injector Helper doar în citire.
- Oferă interfața în 30 de limbi, cu teme luminoasă și întunecată.

Kode Injector nu are servicii de analiză, publicitate sau un backend operat de
dezvoltator. Când o regulă corespunde, codul selectat este pus la dispoziția
paginii site-ului configurat, iar adresa URL a fișierului JavaScript este
inclusă în jurnalul de diagnostic din consola paginii. Configurați numai cod și
site-uri web în care aveți încredere. Consultați politica de confidențialitate
pentru detalii.

După instalare, deschideți setările Kode Injector și urmați indicația pentru
accesul la fișiere. Adăugați o regulă pentru un site web, selectați codul local
și reîncărcați pagina.
