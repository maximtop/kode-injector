# Microsoft Edge Add-ons -kauppasivu — suomi

- Locale: `fi`
- Product name: `Kode Injector`

## Täydellinen kuvaus

Kode Injector yhdistää paikalliset JavaScript- ja CSS-tiedostot verkkosivustoihin, joilla tarvitset niitä. Luo sääntö isäntänimelle, valitse paikallinen JS-tiedosto, CSS-tiedosto tai molemmat, niin laajennus ottaa koodisi automaattisesti käyttöön aina, kun avaat vastaavan sivun.

Se on tarkoitettu verkkokehittäjille, laadunvarmistajille ja suunnittelijoille, joiden täytyy testata korjausta, automatisoida toistuva tarkistus, muokata käytössä olevan sivuston asettelua tai verrata paikallista koontiversiota testi- tai tuotantoympäristöön liittämättä samaa koodikatkelmaa DevToolsiin jokaisen uudelleenlatauksen jälkeen.

Ominaisuudet:

- Suorita paikallinen JavaScript ja CSS automaattisesti vastaavilla verkkosivustoilla.
- Luo, muokkaa, monista, keskeytä ja poista sääntöjä selkeällä asetussivulla.
- Ota käyttöön tai poista käytöstä yksittäisiä tiedostoja, yksi verkkosivusto tai kaikki injektiot kerralla.
- Tarkastele vastaavia sääntöjä ja muuta nykyisen sivuston tilaa työkalupalkin ponnahdusikkunasta.
- Käytä Microsoft Edgen sisäänrakennettua paikallisten tiedostojen käyttöä tai valitse lisäasetuksena vain luku -tilassa toimiva Kode Injector Helper.
- Käytä käyttöliittymää 30 kielellä sekä vaalealla tai tummalla teemalla.

Kode Injector ei käytä analytiikkapalvelua, mainontaa tai kehittäjän ylläpitämää taustapalvelua. Kun sääntö vastaa sivustoa, valittu koodi annetaan määritetyn verkkosivuston sivun käyttöön ja JavaScript-tiedoston URL-osoite lisätään kyseisen sivun konsolin diagnostiikkalokiin. Määritä vain koodia ja verkkosivustoja, joihin luotat. Lisätietoja on tietosuojakäytännössä.

Avaa asennuksen jälkeen Kode Injectorin asetukset ja noudata tiedostokäyttöä koskevaa kehotetta. Lisää verkkosivustolle sääntö, valitse paikallinen koodisi ja lataa sivu uudelleen.
