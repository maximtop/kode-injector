# Záznam v Microsoft Edge Add-ons — čeština

- Locale: `cs`
- Product name: `Kode Injector`

## Úplný popis

Kode Injector propojuje místní soubory JavaScriptu a CSS s weby, na kterých je potřebujete. Vytvořte pravidlo pro název hostitele, zvolte místní soubor JS, soubor CSS nebo oba a rozšíření váš kód automaticky použije pokaždé, když otevřete odpovídající stránku.

Je určené webovým vývojářům, testerům a návrhářům, kteří potřebují ověřit opravu, automatizovat opakovanou kontrolu, upravit vzhled živého webu nebo porovnat místní sestavení s testovacím či produkčním prostředím, aniž by po každém načtení znovu vkládali stejný úryvek do DevTools.

Funkce:

- Automatické spouštění místního JavaScriptu a CSS na odpovídajících webech.
- Vytváření, úpravy, duplikování, pozastavení a mazání pravidel na přehledné stránce možností.
- Zapnutí nebo vypnutí jednotlivých souborů, jednoho webu nebo všech injekcí najednou.
- Zobrazení odpovídajících pravidel a změna stavu aktuálního webu z vyskakovacího okna na panelu nástrojů.
- Použití integrovaného přístupu Microsoft Edge k místním souborům nebo volitelného Kode Injector Helperu pouze pro čtení jako pokročilé alternativy.
- Rozhraní ve 30 jazycích se světlým a tmavým motivem.

Kode Injector nepoužívá analytickou službu, reklamu ani server provozovaný vývojářem. Když pravidlo odpovídá, vybraný kód je zpřístupněn stránce nakonfigurovaného webu a URL souboru JavaScriptu se uvede v diagnostickém záznamu konzole této stránky. Nastavujte pouze kód a weby, kterým důvěřujete. Podrobnosti najdete v zásadách ochrany osobních údajů.

Po instalaci otevřete nastavení Kode Injectoru a postupujte podle výzvy k přístupu k souborům. Přidejte pravidlo pro web, vyberte místní kód a stránku znovu načtěte.
