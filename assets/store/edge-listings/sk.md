# Záznam v Microsoft Edge Add-ons — slovenčina

- Locale: `sk`
- Product name: `Kode Injector`

## Úplný popis

Kode Injector prepája miestne súbory JavaScriptu a CSS s webmi, na ktorých ich
potrebujete. Vytvorte pravidlo pre názov hostiteľa, vyberte miestny súbor JS,
súbor CSS alebo oba a rozšírenie automaticky použije váš kód vždy, keď otvoríte
zodpovedajúcu stránku.

Je určené webovým vývojárom, QA technikom a dizajnérom, ktorí potrebujú otestovať
opravu, automatizovať opakovanú kontrolu, upraviť rozloženie aktívneho webu alebo
porovnať miestne zostavenie s testovacím či produkčným prostredím bez toho, aby
po každom opätovnom načítaní vkladali rovnaký úryvok do DevTools.

Funkcie:

- Automatické spúšťanie miestneho JavaScriptu a CSS na zodpovedajúcich weboch.
- Vytváranie, úprava, duplikovanie, pozastavenie a odstraňovanie pravidiel na
  prehľadnej stránke možností.
- Zapnutie alebo vypnutie jednotlivých súborov, jedného webu alebo všetkých
  vložení naraz.
- Zobrazenie zodpovedajúcich pravidiel a zmena stavu aktuálneho webu z
  kontextového okna na paneli nástrojov.
- Použitie vstavaného prístupu Microsoft Edge k miestnym súborom alebo
  voliteľného Kode Injector Helpera iba na čítanie ako pokročilej alternatívy.
- Rozhranie v 30 jazykoch so svetlým a tmavým motívom.

Kode Injector nepoužíva analytickú službu, reklamu ani serverovú časť
prevádzkovanú vývojárom. Keď sa pravidlo zhoduje, vybraný kód sa sprístupní
stránke nakonfigurovaného webu a URL súboru JavaScriptu sa zahrnie do
diagnostického záznamu konzoly tejto stránky. Nastavujte iba kód a weby, ktorým
dôverujete. Podrobnosti nájdete v zásadách ochrany osobných údajov.

Po inštalácii otvorte nastavenia Kode Injector a postupujte podľa výzvy na
prístup k súborom. Pridajte pravidlo pre web, vyberte miestny kód a znova
načítajte stránku.
