# รายการ Microsoft Edge Add-ons — ภาษาไทย

- Locale: `th`
- Product name: `Kode Injector`

## คำอธิบายฉบับเต็ม

Kode Injector เชื่อมโยงไฟล์ JavaScript และ CSS ในเครื่องกับเว็บไซต์ที่คุณต้องการใช้งาน
สร้างกฎสำหรับชื่อโฮสต์ เลือกไฟล์ JS ในเครื่อง ไฟล์ CSS หรือทั้งสองอย่าง
แล้วส่วนขยายจะใช้โค้ดของคุณโดยอัตโนมัติทุกครั้งที่คุณเปิดหน้าที่ตรงกัน

ส่วนขยายนี้สร้างขึ้นสำหรับนักพัฒนาเว็บ วิศวกร QA และนักออกแบบที่ต้องการทดสอบการแก้ไข
ทำการตรวจสอบที่ทำซ้ำให้เป็นอัตโนมัติ ปรับเค้าโครงของเว็บไซต์ที่ใช้งานอยู่
หรือเปรียบเทียบบิลด์ในเครื่องกับสภาพแวดล้อมทดสอบหรือใช้งานจริง
โดยไม่ต้องวางข้อมูลโค้ดเดิมใน DevTools หลังการโหลดซ้ำทุกครั้ง

คุณสมบัติ:

- เรียกใช้ JavaScript และ CSS ในเครื่องโดยอัตโนมัติบนเว็บไซต์ที่ตรงกัน
- สร้าง แก้ไข ทำสำเนา หยุดชั่วคราว และลบกฎจากหน้าตัวเลือกที่ใช้งานง่าย
- เปิดหรือปิดไฟล์แต่ละไฟล์ เว็บไซต์หนึ่งแห่ง หรือการแทรกทั้งหมดพร้อมกัน
- ดูกฎที่ตรงกันและเปลี่ยนสถานะของเว็บไซต์ปัจจุบันจากป๊อปอัปบนแถบเครื่องมือ
- ใช้การเข้าถึงไฟล์ในเครื่องที่มีมาใน Microsoft Edge หรือเลือกใช้ Kode Injector Helper
  แบบอ่านอย่างเดียวเป็นทางเลือกขั้นสูง
- ใช้อินเทอร์เฟซได้ 30 ภาษา พร้อมธีมสว่างและมืด

Kode Injector ไม่มีบริการวิเคราะห์ โฆษณา หรือระบบแบ็กเอนด์ที่ดำเนินการโดยนักพัฒนา
เมื่อกฎตรงกัน โค้ดที่เลือกจะถูกเปิดเผยต่อหน้าของเว็บไซต์ที่กำหนดค่าไว้ และ URL ของไฟล์
JavaScript จะรวมอยู่ในบันทึกการวินิจฉัยของคอนโซลในหน้านั้น
กำหนดค่าเฉพาะโค้ดและเว็บไซต์ที่คุณเชื่อถือเท่านั้น
โปรดอ่านนโยบายความเป็นส่วนตัวเพื่อดูรายละเอียด

หลังการติดตั้ง ให้เปิดการตั้งค่า Kode Injector และทำตามข้อความแจ้งการเข้าถึงไฟล์
เพิ่มกฎสำหรับเว็บไซต์ เลือกโค้ดในเครื่อง แล้วโหลดหน้าเว็บซ้ำ
