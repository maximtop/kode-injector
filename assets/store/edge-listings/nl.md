# Microsoft Edge Add-ons-vermelding — Nederlands

- Locale: `nl`
- Product name: `Kode Injector`

## Volledige beschrijving

Kode Injector koppelt lokale JavaScript- en CSS-bestanden aan de websites waar u ze nodig hebt. Maak een regel voor een hostnaam, kies een JS-bestand, een CSS-bestand of beide en de extensie past uw code automatisch toe wanneer u een overeenkomende pagina opent.

De extensie is gemaakt voor webontwikkelaars, QA-engineers en ontwerpers die een oplossing willen testen, een terugkerende controle willen automatiseren, de lay-out van een live website willen aanpassen of een lokale build met staging of productie willen vergelijken zonder na elke herlading hetzelfde fragment in DevTools te plakken.

Functies:

- Voer lokale JavaScript en CSS automatisch uit op overeenkomende websites.
- Maak, bewerk, dupliceer, pauzeer en verwijder regels op een overzichtelijke pagina Instellingen.
- Schakel afzonderlijke bestanden, één website of alle injecties tegelijk in of uit.
- Bekijk overeenkomende regels en wijzig de status van de huidige website via de werkbalkpop-up.
- Gebruik de ingebouwde lokale bestandstoegang van Microsoft Edge of kies de alleen-lezen Kode Injector Helper als geavanceerd alternatief.
- Gebruik de interface in 30 talen met lichte en donkere thema’s.

Kode Injector heeft geen analyseservice, advertenties of een door de ontwikkelaar beheerde backend. Wanneer een regel overeenkomt, wordt de geselecteerde code beschikbaar voor de pagina van de geconfigureerde website en wordt de URL van het JavaScript-bestand opgenomen in het diagnostische consolelogboek van die pagina. Configureer alleen code en websites die u vertrouwt. Raadpleeg het privacybeleid voor meer informatie.

Open na de installatie de instellingen van Kode Injector en volg de aanwijzingen voor bestandstoegang. Voeg een regel voor een website toe, selecteer uw lokale code en laad de pagina opnieuw.
