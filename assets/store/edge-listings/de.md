- Product name: `Kode Injector`

## Vollständige Beschreibung

Kode Injector verknüpft lokale JavaScript- und CSS-Dateien mit den Websites, auf denen Sie sie benötigen. Erstellen Sie eine Regel für einen Hostnamen und wählen Sie eine lokale JS-Datei, eine CSS-Datei oder beides aus. Die Erweiterung wendet Ihren Code dann automatisch an, sobald Sie eine passende Seite öffnen.

Sie richtet sich an Webentwickler, QA-Fachleute und Designer, die eine Korrektur testen, eine wiederkehrende Prüfung automatisieren, das Layout einer Live-Website anpassen oder einen lokalen Build mit einer Staging- oder Produktionsumgebung vergleichen möchten, ohne nach jedem Neuladen dasselbe Snippet in die DevTools einzufügen.

Funktionen:

- Lokales JavaScript und CSS automatisch auf passenden Websites ausführen.
- Regeln auf einer übersichtlichen Optionsseite erstellen, bearbeiten, duplizieren, pausieren und löschen.
- Einzelne Dateien, eine Website oder alle Injektionen gleichzeitig aktivieren oder deaktivieren.
- Passende Regeln anzeigen und den Status der aktuellen Website über das Pop-up in der Symbolleiste ändern.
- Den integrierten Zugriff von Microsoft Edge auf lokale Dateien verwenden oder sich als erweiterte Alternative für den schreibgeschützten Kode Injector Helper entscheiden.
- Die Oberfläche in 30 Sprachen sowie mit hellem und dunklem Design nutzen.

Kode Injector nutzt weder Analysedienste noch Werbung oder ein vom Entwickler betriebenes Backend. Wenn eine Regel zutrifft, wird der ausgewählte Code für die Seite der konfigurierten Website bereitgestellt. Die URL der JavaScript-Datei wird außerdem in das Diagnoseprotokoll der Seitenkonsole aufgenommen. Konfigurieren Sie nur Code und Websites, denen Sie vertrauen. Weitere Einzelheiten finden Sie in der Datenschutzerklärung.

Öffnen Sie nach der Installation die Einstellungen von Kode Injector und folgen Sie der Aufforderung zum Dateizugriff. Fügen Sie eine Regel für eine Website hinzu, wählen Sie Ihren lokalen Code aus und laden Sie die Seite neu.
