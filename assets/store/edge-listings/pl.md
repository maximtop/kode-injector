# Oferta w Microsoft Edge Add-ons — polski

- Locale: `pl`
- Product name: `Kode Injector`

## Pełny opis

Kode Injector łączy lokalne pliki JavaScript i CSS z witrynami, w których ich potrzebujesz. Utwórz regułę dla nazwy hosta, wybierz plik JS, plik CSS lub oba, a rozszerzenie automatycznie zastosuje Twój kod po każdym otwarciu pasującej strony.

Rozszerzenie powstało dla programistów stron internetowych, inżynierów QA i projektantów, którzy chcą przetestować poprawkę, zautomatyzować powtarzalną kontrolę, dostosować układ działającej witryny albo porównać lokalną kompilację ze środowiskiem stagingowym lub produkcyjnym bez wklejania tego samego fragmentu do DevTools po każdym odświeżeniu.

Funkcje:

- Automatyczne uruchamianie lokalnego JavaScriptu i CSS w pasujących witrynach.
- Tworzenie, edytowanie, duplikowanie, wstrzymywanie i usuwanie reguł na przejrzystej stronie Ustawienia.
- Włączanie i wyłączanie pojedynczych plików, jednej witryny lub wszystkich wstrzyknięć jednocześnie.
- Wyświetlanie pasujących reguł i zmiana stanu bieżącej witryny z poziomu wyskakującego okna paska narzędzi.
- Korzystanie z wbudowanego dostępu Microsoft Edge do plików lokalnych albo wybór działającego tylko w trybie odczytu Kode Injector Helper jako opcji zaawansowanej.
- Interfejs w 30 językach z jasnym i ciemnym motywem.

Kode Injector nie zawiera usługi analitycznej, reklam ani backendu obsługiwanego przez dewelopera. Gdy reguła pasuje, wybrany kod jest udostępniany stronie skonfigurowanej witryny, a adres URL pliku JavaScript trafia do diagnostycznego dziennika konsoli tej strony. Konfiguruj tylko kod i witryny, którym ufasz. Szczegóły znajdziesz w polityce prywatności.

Po instalacji otwórz ustawienia Kode Injector i postępuj zgodnie z instrukcjami dostępu do plików. Dodaj regułę dla witryny, wybierz lokalny kod i odśwież stronę.
