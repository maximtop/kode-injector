# قائمة Microsoft Edge Add-ons — العربية

- Locale: `ar`
- Product name: `Kode Injector`

## الوصف الكامل

يربط Kode Injector ملفات JavaScript وCSS المحلية بالمواقع التي تحتاج إليها. أنشئ قاعدة لاسم مضيف، واختر ملف JS محليًا أو ملف CSS أو كليهما، وستطبّق الإضافة الكود تلقائيًا كلما فتحت صفحة مطابقة.

صُممت الإضافة لمطوري الويب ومهندسي ضمان الجودة والمصممين الذين يحتاجون إلى اختبار إصلاح، أو أتمتة فحص متكرر، أو تعديل تخطيط مباشر، أو مقارنة إصدار محلي ببيئة الاختبار أو الإنتاج من دون لصق المقتطف نفسه في DevTools بعد كل إعادة تحميل.

الميزات:

- تشغيل JavaScript وCSS المحليين تلقائيًا على المواقع المطابقة.
- إنشاء القواعد وتعديلها وتكرارها وإيقافها مؤقتًا وحذفها من صفحة خيارات واضحة.
- تفعيل ملفات فردية أو تعطيلها، أو التحكم في موقع واحد، أو إيقاف جميع عمليات الحقن دفعة واحدة.
- عرض القواعد المطابقة وتغيير حالة الموقع الحالي من نافذة شريط الأدوات المنبثقة.
- استخدام وصول Microsoft Edge المدمج إلى الملفات المحلية، أو الاشتراك في Kode Injector Helper المخصص للقراءة فقط كخيار متقدم.
- استخدام الواجهة بثلاثين لغة، مع سمة فاتحة وأخرى داكنة.

لا يستخدم Kode Injector خدمة تحليلات أو إعلانات أو خادمًا خلفيًا يديره المطور. عند مطابقة قاعدة، يُتاح الكود المحدد لصفحة الموقع الذي هيأته، ويظهر عنوان URL لملف JavaScript في سجل التشخيص بوحدة تحكم تلك الصفحة. لا تهيئ إلا الأكواد والمواقع التي تثق بها. راجع سياسة الخصوصية لمعرفة التفاصيل.

بعد التثبيت، افتح إعدادات Kode Injector واتبع مطالبة الوصول إلى الملفات. أضف قاعدة لموقع، وحدد الكود المحلي، ثم أعد تحميل الصفحة.
