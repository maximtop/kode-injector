- Product name: `Kode Injector`

## 完整说明

Kode Injector 可将本地 JavaScript 和 CSS 文件连接到您需要使用它们的网站。
为主机名创建规则，选择本地 JS 文件、CSS 文件或两者，之后每当您打开匹配的页面时，
扩展都会自动应用您的代码。

它专为 Web 开发者、QA 工程师和设计师打造，可用于测试修复、自动执行重复检查、
调整线上布局，或比较本地构建与预发布或生产环境，而不必在每次重新加载后都将同一段
代码粘贴到 DevTools 中。

功能：

- 在匹配的网站上自动运行本地 JavaScript 和 CSS。
- 在简洁的选项页面中创建、编辑、复制、暂停和删除规则。
- 启用或禁用单个文件、某个网站或一次停用所有注入。
- 从工具栏弹出窗口查看匹配规则并更改当前网站的状态。
- 使用 Microsoft Edge 内置的本地文件访问功能，或选择只读的 Kode Injector Helper
  作为高级替代方案。
- 使用支持 30 种语言以及浅色和深色主题的界面。

Kode Injector 不使用分析服务、广告或由开发者运营的后端。当规则匹配时，所选代码会
提供给已配置网站的页面，而 JavaScript 文件 URL 会包含在该页面的诊断控制台日志中。
请仅配置您信任的代码和网站。有关详细信息，请查看隐私政策。

安装后，请打开 Kode Injector 设置并按照文件访问提示操作。为网站添加规则，选择您的
本地代码，然后重新加载页面。
