# Сторінка Microsoft Edge Add-ons — українська

- Locale: `uk`
- Product name: `Kode Injector`

## Повний опис

Kode Injector пов’язує локальні файли JavaScript і CSS із вебсайтами, де вони
вам потрібні. Створіть правило для імені хоста, виберіть локальний файл JS,
файл CSS або обидва файли, і розширення автоматично застосовуватиме ваш код
щоразу, коли ви відкриваєте відповідну сторінку.

Розширення створено для веброзробників, QA-інженерів і дизайнерів, яким потрібно
перевірити виправлення, автоматизувати повторювану перевірку, налаштувати макет
активного сайту або порівняти локальну збірку з тестовим чи робочим середовищем,
не вставляючи той самий фрагмент у DevTools після кожного перезавантаження.

Можливості:

- Автоматичний запуск локальних JavaScript і CSS на відповідних вебсайтах.
- Створення, редагування, дублювання, призупинення та видалення правил на
  зручній сторінці налаштувань.
- Увімкнення або вимкнення окремих файлів, одного вебсайту чи всіх вставок
  одночасно.
- Перегляд відповідних правил і зміна стану поточного сайту зі спливного вікна
  панелі інструментів.
- Використання вбудованого доступу Microsoft Edge до локальних файлів або
  доступного як розширений варіант Kode Injector Helper, що працює лише для
  читання.
- Інтерфейс 30 мовами зі світлою та темною темами.

Kode Injector не використовує службу аналітики, рекламу чи серверну частину під
керуванням розробника. Коли правило збігається, вибраний код стає доступним
сторінці налаштованого вебсайту, а URL-адреса файлу JavaScript додається до
діагностичного журналу консолі цієї сторінки. Налаштовуйте лише код і вебсайти,
яким довіряєте. Докладні відомості наведено в політиці конфіденційності.

Після встановлення відкрийте налаштування Kode Injector і дотримуйтеся підказки
щодо доступу до файлів. Додайте правило для вебсайту, виберіть локальний код і
перезавантажте сторінку.
