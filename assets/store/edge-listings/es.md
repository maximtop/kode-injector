# Ficha de Microsoft Edge Add-ons — español

- Locale: `es`
- Product name: `Kode Injector`

## Descripción completa

Kode Injector conecta archivos JavaScript y CSS locales con los sitios web donde los necesitas. Crea una regla para un nombre de host, elige un archivo JS local, un archivo CSS o ambos, y la extensión aplicará tu código automáticamente cada vez que abras una página coincidente.

Está diseñada para desarrolladores web, profesionales de control de calidad y diseñadores que necesitan probar una corrección, automatizar una comprobación repetitiva, ajustar el diseño de un sitio publicado o comparar una compilación local con un entorno de pruebas o producción sin pegar el mismo fragmento en DevTools después de cada recarga.

Funciones:

- Ejecuta JavaScript y CSS locales automáticamente en los sitios web coincidentes.
- Crea, edita, duplica, pausa y elimina reglas desde una página de opciones clara.
- Activa o desactiva archivos individuales, un sitio web o todas las inyecciones a la vez.
- Consulta las reglas coincidentes y cambia el estado del sitio actual desde la ventana emergente de la barra de herramientas.
- Usa el acceso integrado de Microsoft Edge a los archivos locales o, como alternativa avanzada, activa Kode Injector Helper de solo lectura.
- Usa la interfaz en 30 idiomas, con temas claro y oscuro.

Kode Injector no tiene servicios de análisis, publicidad ni un servidor administrado por el desarrollador. Cuando una regla coincide, el código seleccionado queda expuesto a la página del sitio web configurado, y la URL del archivo JavaScript se incluye en el registro de diagnóstico de la consola de esa página. Configura únicamente código y sitios web en los que confíes. Consulta la política de privacidad para obtener más información.

Después de la instalación, abre los ajustes de Kode Injector y sigue la indicación para habilitar el acceso a archivos. Añade una regla para un sitio web, selecciona tu código local y vuelve a cargar la página.
