# Καταχώριση στο Microsoft Edge Add-ons — Ελληνικά

- Locale: `el`
- Product name: `Kode Injector`

## Πλήρης περιγραφή

Το Kode Injector συνδέει τοπικά αρχεία JavaScript και CSS με τους ιστοτόπους όπου τα χρειάζεστε. Δημιουργήστε έναν κανόνα για ένα όνομα κεντρικού υπολογιστή, επιλέξτε ένα τοπικό αρχείο JS, ένα αρχείο CSS ή και τα δύο και η επέκταση θα εφαρμόζει αυτόματα τον κώδικά σας κάθε φορά που ανοίγετε μια σελίδα που αντιστοιχεί.

Έχει σχεδιαστεί για προγραμματιστές ιστού, μηχανικούς διασφάλισης ποιότητας και σχεδιαστές που χρειάζεται να δοκιμάσουν μια διόρθωση, να αυτοματοποιήσουν έναν επαναλαμβανόμενο έλεγχο, να προσαρμόσουν τη διάταξη ενός ενεργού ιστοτόπου ή να συγκρίνουν μια τοπική έκδοση με περιβάλλον δοκιμών ή παραγωγής, χωρίς να επικολλούν το ίδιο απόσπασμα στα DevTools μετά από κάθε επαναφόρτωση.

Δυνατότητες:

- Αυτόματη εκτέλεση τοπικού JavaScript και CSS σε ιστοτόπους που αντιστοιχούν.
- Δημιουργία, επεξεργασία, αντιγραφή, παύση και διαγραφή κανόνων από μια οργανωμένη σελίδα επιλογών.
- Ενεργοποίηση ή απενεργοποίηση μεμονωμένων αρχείων, ενός ιστοτόπου ή όλων των εγχύσεων μαζί.
- Προβολή των κανόνων που αντιστοιχούν και αλλαγή της κατάστασης του τρέχοντος ιστοτόπου από το αναδυόμενο παράθυρο της γραμμής εργαλείων.
- Χρήση της ενσωματωμένης πρόσβασης του Microsoft Edge σε τοπικά αρχεία ή προαιρετική χρήση του Kode Injector Helper μόνο για ανάγνωση ως προηγμένη εναλλακτική.
- Χρήση της διεπαφής σε 30 γλώσσες, με φωτεινό και σκοτεινό θέμα.

Το Kode Injector δεν διαθέτει υπηρεσία ανάλυσης, διαφημίσεις ή σύστημα υποστήριξης που λειτουργεί ο προγραμματιστής. Όταν ένας κανόνας αντιστοιχεί, ο επιλεγμένος κώδικας εκτίθεται στη σελίδα του ρυθμισμένου ιστοτόπου και η διεύθυνση URL του αρχείου JavaScript περιλαμβάνεται στο διαγνωστικό αρχείο καταγραφής της κονσόλας της σελίδας. Ρυθμίστε μόνο κώδικα και ιστοτόπους που εμπιστεύεστε. Ανατρέξτε στην πολιτική απορρήτου για λεπτομέρειες.

Μετά την εγκατάσταση, ανοίξτε τις ρυθμίσεις του Kode Injector και ακολουθήστε την προτροπή πρόσβασης σε αρχεία. Προσθέστε έναν κανόνα για έναν ιστότοπο, επιλέξτε τον τοπικό σας κώδικα και επαναφορτώστε τη σελίδα.
