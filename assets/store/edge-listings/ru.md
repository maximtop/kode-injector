# Карточка Microsoft Edge Add-ons — русский

- Locale: `ru`
- Product name: `Kode Injector`

## Полное описание

Kode Injector связывает локальные файлы JavaScript и CSS с сайтами, на которых
они нужны. Создайте правило для имени хоста, выберите локальный файл JS, файл
CSS или оба файла, и расширение будет автоматически применять ваш код каждый
раз, когда вы открываете подходящую страницу.

Расширение создано для веб-разработчиков, QA-инженеров и дизайнеров, которым
нужно проверить исправление, автоматизировать повторяющуюся проверку, изменить
макет работающего сайта или сравнить локальную сборку с тестовой либо
продукционной средой, не вставляя один и тот же фрагмент в DevTools после
каждой перезагрузки.

Возможности:

- Автоматический запуск локальных JavaScript и CSS на подходящих сайтах.
- Создание, изменение, дублирование, приостановка и удаление правил на удобной
  странице настроек.
- Включение и отключение отдельных файлов, одного сайта или всех вставок
  одновременно.
- Просмотр подходящих правил и изменение состояния текущего сайта во
  всплывающем окне на панели инструментов.
- Использование встроенного доступа Microsoft Edge к локальным файлам или
  доступного в качестве расширенной альтернативы Kode Injector Helper, который
  работает только на чтение.
- Интерфейс на 30 языках со светлой и тёмной темами.

Kode Injector не использует аналитику, рекламу или серверную часть под
управлением разработчика. Когда правило совпадает, выбранный код становится
доступен странице настроенного сайта, а URL файла JavaScript добавляется в
диагностический журнал консоли этой страницы. Настраивайте только код и сайты,
которым доверяете. Подробности приведены в политике конфиденциальности.

После установки откройте настройки Kode Injector и следуйте подсказке о доступе
к файлам. Добавьте правило для сайта, выберите локальный код и перезагрузите
страницу.
