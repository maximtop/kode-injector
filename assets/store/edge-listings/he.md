# רישום בתוספים של Microsoft Edge — עברית

- Locale: `he`
- Product name: `Kode Injector`

## תיאור מלא

Kode Injector מחבר קובצי JavaScript ו-CSS מקומיים לאתרים שבהם אתם זקוקים להם. צרו כלל עבור שם מארח, בחרו קובץ JS, קובץ CSS או את שניהם, והתוסף יחיל את הקוד שלכם אוטומטית בכל פעם שתפתחו דף תואם.

התוסף מיועד למפתחי אתרים, למהנדסי QA ולמעצבים שצריכים לבדוק תיקון, להפוך בדיקה חוזרת לאוטומטית, להתאים פריסה באתר פעיל או להשוות בנייה מקומית לסביבת staging או production, בלי להדביק שוב את אותו קטע קוד ב-DevTools לאחר כל טעינה מחדש.

תכונות:

- הפעלה אוטומטית של JavaScript ו-CSS מקומיים באתרים תואמים.
- יצירה, עריכה, שכפול, השהיה ומחיקה של כללים מדף הגדרות ממוקד.
- הפעלה או השבתה של קבצים בודדים, אתר אחד או כל ההזרקות בבת אחת.
- הצגת כללים תואמים ושינוי מצב האתר הנוכחי מהחלונית בסרגל הכלים.
- שימוש בגישה המובנית של Microsoft Edge לקבצים מקומיים, או בחירה ב-Kode Injector Helper לקריאה בלבד כאפשרות מתקדמת.
- ממשק ב-30 שפות עם ערכות נושא בהירה וכהה.

Kode Injector אינו כולל שירות ניתוח נתונים, פרסום או שרת אחורי שמפעיל המפתח. כשכלל תואם, הקוד שנבחר נחשף לדף באתר שהוגדר, וכתובת קובץ ה-JavaScript מופיעה ביומן האבחון של מסוף הדף. הגדירו רק קוד ואתרים שאתם נותנים בהם אמון. לפרטים נוספים, עיינו במדיניות הפרטיות.

לאחר ההתקנה, פתחו את הגדרות Kode Injector ופעלו לפי ההנחיה לגישה לקבצים. הוסיפו כלל לאתר, בחרו את הקוד המקומי שלכם וטענו את הדף מחדש.
