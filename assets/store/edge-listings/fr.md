- Product name: `Kode Injector`

## Description complète

Kode Injector relie des fichiers JavaScript et CSS locaux aux sites web sur lesquels vous en avez besoin. Créez une règle pour un nom d’hôte, choisissez un fichier JS local, un fichier CSS ou les deux, et l’extension appliquera automatiquement votre code chaque fois que vous ouvrirez une page correspondante.

Elle est conçue pour les développeurs web, les ingénieurs QA et les designers qui doivent tester une correction, automatiser une vérification répétitive, ajuster la mise en page d’un site en ligne ou comparer une version locale à un environnement de préproduction ou de production, sans coller le même extrait dans les DevTools après chaque rechargement.

Fonctionnalités :

- Exécuter automatiquement du JavaScript et du CSS locaux sur les sites web correspondants.
- Créer, modifier, dupliquer, mettre en pause et supprimer des règles depuis une page d’options claire.
- Activer ou désactiver des fichiers individuels, un site web ou toutes les injections à la fois.
- Afficher les règles correspondantes et modifier l’état du site actuel depuis la fenêtre pop-up de la barre d’outils.
- Utiliser l’accès intégré de Microsoft Edge aux fichiers locaux ou, comme option avancée, activer Kode Injector Helper en lecture seule.
- Utiliser l’interface dans 30 langues, avec un thème clair ou sombre.

Kode Injector ne comporte aucun service d’analyse, aucune publicité et aucun serveur géré par le développeur. Lorsqu’une règle correspond, le code sélectionné est exposé à la page du site web configuré, et l’URL du fichier JavaScript figure dans le journal de diagnostic de la console de cette page. Ne configurez que du code et des sites web auxquels vous faites confiance. Consultez la politique de confidentialité pour plus de détails.

Après l’installation, ouvrez les paramètres de Kode Injector et suivez l’invite d’accès aux fichiers. Ajoutez une règle pour un site web, sélectionnez votre code local, puis rechargez la page.
