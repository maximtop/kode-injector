- Product name: `Kode Injector`

## 전체 설명

Kode Injector는 필요한 웹사이트에 로컬 JavaScript 및 CSS 파일을 연결합니다. 호스트 이름에 대한 규칙을 만들고 JS 파일, CSS 파일 또는 둘 다를 선택하면 일치하는 페이지를 열 때마다 확장 프로그램이 코드를 자동으로 적용합니다.

수정 사항 테스트, 반복 검사 자동화, 실제 사이트의 레이아웃 조정 또는 로컬 빌드와 스테이징이나 프로덕션 환경 비교가 필요한 웹 개발자, QA 엔지니어 및 디자이너를 위한 도구입니다. 새로 고칠 때마다 같은 코드 조각을 DevTools에 다시 붙여 넣을 필요가 없습니다.

기능:

- 일치하는 웹사이트에서 로컬 JavaScript와 CSS를 자동으로 실행합니다.
- 간결한 설정 페이지에서 규칙을 생성, 편집, 복제, 일시 중지 및 삭제합니다.
- 개별 파일, 웹사이트 하나 또는 모든 인젝션을 한 번에 활성화하거나 비활성화합니다.
- 도구 모음 팝업에서 일치하는 규칙을 보고 현재 사이트의 상태를 변경합니다.
- Microsoft Edge의 기본 로컬 파일 액세스를 사용하거나 고급 대안으로 읽기 전용 Kode Injector Helper를 선택합니다.
- 밝은 테마와 어두운 테마를 갖춘 30개 언어 인터페이스를 사용합니다.

Kode Injector에는 분석 서비스, 광고 또는 개발자가 운영하는 백엔드가 없습니다. 규칙이 일치하면 선택한 코드가 구성된 웹사이트의 페이지에 노출되고 JavaScript 파일 URL이 해당 페이지의 진단 콘솔 로그에 포함됩니다. 신뢰하는 코드와 웹사이트만 구성하세요. 자세한 내용은 개인정보처리방침을 확인하세요.

설치 후 Kode Injector 설정을 열고 파일 액세스 안내를 따르세요. 웹사이트에 대한 규칙을 추가하고 로컬 코드를 선택한 다음 페이지를 새로 고치세요.
