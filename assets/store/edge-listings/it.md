# Scheda Microsoft Edge Add-ons — Italiano

- Locale: `it`
- Product name: `Kode Injector`

## Descrizione completa

Kode Injector collega i file JavaScript e CSS locali ai siti web in cui ti servono. Crea una regola per un nome host, scegli un file JS, un file CSS o entrambi e l’estensione applicherà automaticamente il tuo codice ogni volta che apri una pagina corrispondente.

È pensato per sviluppatori web, ingegneri QA e designer che devono verificare una correzione, automatizzare un controllo ripetitivo, modificare il layout di un sito attivo o confrontare una build locale con staging o produzione senza incollare lo stesso frammento in DevTools dopo ogni ricaricamento.

Funzionalità:

- Esecuzione automatica di JavaScript e CSS locali sui siti web corrispondenti.
- Creazione, modifica, duplicazione, sospensione ed eliminazione delle regole da una pagina Impostazioni essenziale.
- Attivazione o disattivazione di singoli file, di un sito web o di tutte le iniezioni insieme.
- Visualizzazione delle regole corrispondenti e modifica dello stato del sito corrente dal pop-up della barra degli strumenti.
- Uso dell’accesso ai file locali integrato in Microsoft Edge oppure, come opzione avanzata, di Kode Injector Helper in sola lettura.
- Interfaccia in 30 lingue con temi chiaro e scuro.

Kode Injector non include servizi di analisi, pubblicità o backend gestiti dallo sviluppatore. Quando una regola corrisponde, il codice selezionato viene esposto alla pagina del sito configurato e l’URL del file JavaScript viene incluso nel registro diagnostico della console della pagina. Configura solo codice e siti web di cui ti fidi. Consulta l’informativa sulla privacy per i dettagli.

Dopo l’installazione, apri le impostazioni di Kode Injector e segui la richiesta per l’accesso ai file. Aggiungi una regola per un sito web, seleziona il codice locale e ricarica la pagina.
