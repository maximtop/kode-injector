# Cantuman Microsoft Edge Add-ons — Bahasa Indonesia

- Locale: `id`
- Product name: `Kode Injector`

## Deskripsi lengkap

Kode Injector menghubungkan file JavaScript dan CSS lokal ke situs web tempat Anda membutuhkannya. Buat aturan untuk nama host, pilih file JS, file CSS, atau keduanya, lalu ekstensi akan menerapkan kode Anda secara otomatis setiap kali Anda membuka halaman yang cocok.

Ekstensi ini dibuat untuk pengembang web, engineer QA, dan desainer yang perlu menguji perbaikan, mengotomatiskan pemeriksaan berulang, menyesuaikan tata letak situs aktif, atau membandingkan build lokal dengan staging atau produksi tanpa menempelkan cuplikan yang sama ke DevTools setelah setiap pemuatan ulang.

Fitur:

- Jalankan JavaScript dan CSS lokal secara otomatis di situs web yang cocok.
- Buat, edit, duplikat, jeda, dan hapus aturan dari halaman Pengaturan yang ringkas.
- Aktifkan atau nonaktifkan file tertentu, satu situs web, atau semua injeksi sekaligus.
- Lihat aturan yang cocok dan ubah status situs saat ini dari pop-up bilah alat.
- Gunakan akses file lokal bawaan Microsoft Edge, atau pilih Kode Injector Helper yang hanya-baca sebagai alternatif lanjutan.
- Gunakan antarmuka dalam 30 bahasa dengan tema terang dan gelap.

Kode Injector tidak memiliki layanan analitik, iklan, atau backend yang dioperasikan pengembang. Saat aturan cocok, kode yang dipilih diekspos ke halaman situs web yang dikonfigurasi, dan URL file JavaScript disertakan dalam log konsol diagnostik halaman tersebut. Hanya konfigurasikan kode dan situs web yang Anda percayai. Tinjau kebijakan privasi untuk detailnya.

Setelah instalasi, buka pengaturan Kode Injector dan ikuti petunjuk akses file. Tambahkan aturan untuk situs web, pilih kode lokal Anda, lalu muat ulang halaman.
