- Locale: `pt_BR`
- Product name: `Kode Injector`

## Descrição completa

O Kode Injector conecta arquivos JavaScript e CSS locais aos sites onde você precisa deles. Crie uma regra para um nome de host, escolha um arquivo JS, um arquivo CSS ou ambos, e a extensão aplicará seu código automaticamente sempre que você abrir uma página correspondente.

Ele foi criado para desenvolvedores web, engenheiros de QA e designers que precisam testar uma correção, automatizar uma verificação repetitiva, ajustar o layout de um site ativo ou comparar uma build local com staging ou produção sem colar o mesmo trecho no DevTools após cada recarregamento.

Recursos:

- Execute JavaScript e CSS locais automaticamente nos sites correspondentes.
- Crie, edite, duplique, pause e exclua regras em uma página de Configurações objetiva.
- Ative ou desative arquivos individuais, um site ou todas as injeções de uma só vez.
- Veja as regras correspondentes e altere o estado do site atual pelo pop-up da barra de ferramentas.
- Use o acesso integrado do Microsoft Edge a arquivos locais ou escolha o Kode Injector Helper somente leitura como uma alternativa avançada.
- Use a interface em 30 idiomas com temas claro e escuro.

O Kode Injector não tem serviço de análise, publicidade nem backend operado pelo desenvolvedor. Quando uma regra corresponde, o código selecionado é exposto à página do site configurado, e a URL do arquivo JavaScript é incluída no log de diagnóstico do console dessa página. Configure somente códigos e sites em que você confia. Consulte a política de privacidade para obter detalhes.

Após a instalação, abra as configurações do Kode Injector e siga a solicitação de acesso a arquivos. Adicione uma regra para um site, selecione seu código local e recarregue a página.
